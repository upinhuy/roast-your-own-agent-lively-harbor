## The entry

> I asked my agent for one line; it gave me a roadmap, a disclaimer, and a request for clarification.

99 characters, one line. My agent was asked for a single line and answered with a plan, a hedge, and a question back — so the roast writes itself.

## How it works

`main.ts` validates the line (real text, a single line, 1–140 characters counted as code points) and writes it to `/output/entry.txt`:

```sh
node main.ts
```

No dependencies, pure Node standard library.
